4. Logística de Migración: Dominio y Hosting
   Este es el punto clave para liberar al cliente de los altos costos actuales.

A. El Dominio (victoria132.com)
El dominio pertenece legalmente al cliente, pero actualmente es administrado por la agencia "Consultores Tyren".

Acción Requerida: El cliente debe solicitar a la agencia el Código de Autorización (Auth Code o EPP) del dominio. Con este código, se transferirá la administración del dominio a un registrador propio (ej. Namecheap), devolviéndole el control absoluto al cliente.

Alternativa: Si la agencia no entrega el código de inmediato, el cliente puede exigir acceso para modificar los "Registros A" (DNS) y apuntarlos a nuestro nuevo servidor de forma temporal mientras se procesa la transferencia legal.

B. El Hosting (Servidor)

La página actual está alojada en el ecosistema cerrado de Squarespace, el cual se cancelará, cortando los pagos a la agencia.

Nueva Solución: Se contratará un plan de Shared Hosting optimizado para WordPress (como Hostinger). Estos planes son de alta velocidad y reducen el costo operativo anual del servidor a una fracción de lo que el cliente paga actualmente (estimado en $1,000 - $1,500 MXN anuales, frente a los >$5,300 MXN actuales).
